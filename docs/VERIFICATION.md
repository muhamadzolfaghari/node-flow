## Known scope and unverified behavior

- Converted formats intentionally support documented subsets. Their vendor layout, styling, macros, and execution semantics are not fully reproduced. Original text remains editable and exportable.
- Visual source edits support Mermaid flowcharts (node creation, renaming, 8 shapes, color accents, 6 arrow styles, quick child steps, duplication, direction switching, cascading deletion, edge disconnection), sequence diagrams (participant/actor management, message passing with arrow styles), class diagrams (class addition, field/method declaration, relationships, class removal), state diagrams (state addition with labels, transitions with events, state deletion), entity-relationship diagrams (entity creation, typed attributes with PK/FK flags, relational cardinalities, entity deletion), mindmaps (topic hierarchy, custom-shaped subtopic addition, subtree pruning), git graphs (commit, branch, checkout, and merge), pie charts (chart title editing, weighted slice addition, slice removal), user journey maps (section organization, task addition with satisfaction ratings and actors, task deletion), kanban boards (columns, card addition, card removal), gantt charts (workstream section creation, scheduled task addition with status and duration, task deletion), quadrant charts (point coordinate editing, item addition, point deletion), timelines (period creation, event addition with descriptions, event deletion), sankey diagrams (link flow modeling and removal), xy charts (title updates, bar/line series management), block diagrams (column layout and hardware/system block management), C4 architecture models (Context/Container/Component elements and protocol relations), requirement diagrams (functional/performance requirements, elements, traceability links, deletion), packet & bytefield diagrams (bitfield ranges, single bits, field deletion), and diagram look/theme styling (hand-drawn sketchy mode and theme presets). Other diagram types remain editable through source code.
- Storage is local to this browser; there is no shared cloud persistence or collaborative editing service.
- PDF export embeds a raster image. SVG remains the vector export.
- Optional Qwen model download and WebGPU inference have not been verified in the headless browser. The UI reports unavailable WebGPU and model-loading failures.
- Native mobile touch gestures, OS fullscreen behavior, every vendor syntax variation, and extreme-size real-world projects require further device and fixture testing.
