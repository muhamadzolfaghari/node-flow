Supported formats

38 source formats. “Native” formats render directly; others are converted to an editable preview, and the original source stays recoverable.

See details in the app

FormatExtensionsModeWhat it covers
Mermaid.mmd, .mermaidNativeFlowcharts, ER, UML, mindmaps, Gantt, charts, and C4.

SQL DDL.sqlDerivedCREATE TABLE columns and foreign keys to ER schemas; dialect-specific syntax may need simplification.

Prisma schema.prismaDerivedPrisma model blocks and relations to ER schemas.
Protobuf.protoDerivedProto3 message/enum blocks to class diagrams.

GraphQL SDL.graphql, .gqlDerivedTypes, fields, and relationships to a class diagram.

ERD text.erdDerivedCrow's-foot text (||--o{) and TABLE blocks to ER diagrams.

FreeMind.mmDerivedTopic hierarchy to a mindmap; styling and metadata remain in the original XML.
